# lab-followup — 검진 Lab 이상 후속관리

건강검진에서 흔히 마주치는 세 가지 이상을 "재검 → 감별 → 의뢰" 형식으로 정리한 개인 학습 페이지.

- `urine.html` — 혈뇨·단백뇨 (3회 소변검사, 3·6·12개월 추적, 기립성 단백뇨)
- `liver.html` — 간수치 상승 (패턴 판정, 원인 5개, 영상·자가항체)
- `thyroid.html` — 무증상 갑상선기능이상 (3개월 재검, TSH 10, 고령 기준)

내용 출처: 본인 원노트(Nephro · GI · Endo 학회 정리). 원노트에 없는 값은 "확인 필요"로 표시했다.
개인 학습 정리이며 진료 지침을 대체하지 않는다.
